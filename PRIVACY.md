# Política de Privacidade do Auri

Última atualização: 31 de agosto de 2026.

A extensão Auri conecta a página de leitura aberta no navegador à biblioteca local do Auri Desktop. O Auri Desktop precisa estar instalado no mesmo computador para que a integração funcione.

## Dados lidos

Somente quando você abre ou aciona a extensão, ela pode ler da aba ativa:

- endereço da página e endereço canônico;
- título e nome do site;
- capítulo identificado na página;
- imagem de capa declarada pela página, quando disponível.

A extensão não monitora o histórico nem outras abas em segundo plano. Ela não utiliza um content script permanente.

## Destino e uso dos dados

O contexto necessário da página é enviado localmente ao Auri Desktop por Native Messaging. Ele é usado para localizar uma obra, abrir o Auri, sugerir o cadastro de uma obra ou fonte e atualizar o progresso quando você solicita uma dessas ações.

Nesta versão, não existe servidor Auri envolvido nessa comunicação. A extensão não possui conta, analytics ou telemetry, e não envia os dados da página para cloud. A biblioteca permanece armazenada localmente no computador pelo Auri Desktop.

Os dados não são vendidos nem compartilhados com terceiros pela extensão.

## Publicação desta política

As lojas podem exigir uma URL pública para esta política. Este documento poderá ser publicado futuramente no site oficial ou via GitHub Pages sem alterar as práticas descritas acima.
